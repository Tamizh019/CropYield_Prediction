⚡ Quick Start

Get AgriVision running locally in 4 steps:

# 1. Create & activate virtual environment
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Linux/Mac

# 2. Install dependencies
pip install -r requirements.txt

# 3. Create .env with your Google API key
GOOGLE_API_KEY=your_gemini_api_key_here

# 4. Run the app
python app.py
# → Open http://localhost:5000
💡 Models are pre-trained. If models/ is empty, run python scripts/train_ensemble.py first (takes ~25 minutes).

🏗️ System Architecture

AgriVision is a three-layer full-stack precision agriculture platform:

Frontend Layer

Glassmorphism-styled HTML5/CSS3/JavaScript single-page interface with Chart.js visualisations, dynamic form auto-fill, and real-time result rendering.

Backend Layer

Python 3.10 Flask server handling HTTP routing, form validation, data preprocessing, model inference, and Google Gemini API integration.

ML & AI Layer

  • YieldMax Stacking Ensemble — XGBoost + LightGBM + DNN + Ridge meta-learner for yield prediction
  • Random Forest Classifier — soil-based Smart Crop Advisor (22 crop classes)
  • Google Gemini 2.0 Flash — real-time agronomic insights via structured prompts

🧠 ML Models

YieldMax Ensemble

A stacking ensemble combining three heterogeneous base learners trained on the Indian agricultural yield dataset:

  • XGBoost (300 trees, depth=8, lr=0.05) — categorical feature specialist
  • LightGBM (500 trees, lr=0.03, num_leaves=31) — environmental data expert
  • DNN (256→128→64→32→1, BatchNorm, Dropout, Adam) — interaction pattern detector
  • Ridge Meta-Learner (α=1.0) — trained on 5-fold CV predictions to optimally weight base models

Achieves R² = 0.92 on test set, outperforming any single model by 3–5%.

Smart Crop Advisor

Random Forest Classifier trained on Crop_recommendation.csv (2,200 samples, 22 crop classes). Features: N, P, K, Temperature, Humidity, pH, Rainfall + 6 engineered interaction features. Achieves 99.1% accuracy.

Confidence Scoring

CV = std(xgb_pred, lgbm_pred, dnn_pred) / |mean(predictions)|
Confidence = clip(100 × (1 − CV), 0, 100)

🔌 API Reference

GET /api/model_status
Returns JSON with loaded model flags and prediction count.
GET /api/history
Returns the last 10 prediction history entries.
GET /api/districts/<state>
Returns list of districts for a given state name.
GET /api/estimate_conditions?state=&district=&season=
Returns estimated Temperature, Humidity, Rainfall, pH for the given location and season.
POST /predict_yield_bulk
Upload a CSV file for bulk yield prediction. Returns analytics dashboard with Chart.js charts and downloadable output CSV.

🗃️ Datasets

Yield Dataset (Yield_Data_Ready.csv)

Historical Indian crop yield records. Required columns:

State_Name, District_Name, Crop_Year, Crop,
Area (ha), Production (tonnes), Temperature (°C),
Humidity (%), pH, Rainfall (mm)

Bulk Upload CSV Format

For the bulk predictor, columns can be in either standard or alternate naming:

State_Name (or "State Name"), District_Name (or "Dist Name"),
Crop_Year (or "Year"), Crop, Area (or "Area_ha"),
Temperature (or "Temperature_C"), Humidity (or "Humidity_%"),
pH, Rainfall (or "Rainfall_mm")
💡 Environmental columns (Temperature, Humidity, pH, Rainfall) are optional in bulk uploads — defaults are applied if missing.

🔧 Training the Models

Step 1 — Prepare Dataset

python scripts/prepare_dataset.py

Converts raw CSV to Datasets/Yield_Data_Ready.csv with standardised column names.

Step 2 — Train YieldMax Ensemble

python scripts/train_ensemble.py

Trains XGBoost + LightGBM + DNN + Ridge meta-learner. Takes ~25 minutes. Saves to models/.

Step 3 — Train Crop Recommender

python scripts/train_recommend.py

Trains the Random Forest classifier for crop recommendation.

🚀 Deployment (Hugging Face Spaces)

  1. Create a new Docker Space on huggingface.co/spaces
  2. Push this repo: git push space main
  3. Set secrets: GOOGLE_API_KEY and SECRET_KEY in Space settings
  4. Upload models/*.pkl via the HF Files tab (excluded from git due to size)

The Dockerfile uses Gunicorn with 2 workers, 4 threads, and a 120s timeout on port 7860.
